# 俄罗斯方块游戏

纯 HTML/CSS/JavaScript 实现的经典俄罗斯方块游戏。

## 功能特性

- ✅ 完整的俄罗斯方块游戏逻辑
- ✅ 七种不同形状的方块 (I, J, L, O, S, T, Z)
- ✅ 方块旋转
- ✅ 下一个方块预览
- ✅ 计分系统 (消行越多分数越高)
- ✅ 等级提升 + 难度递增 (速度加快)
- ✅ 键盘控制支持
- ✅ 开始/暂停/重新开始
- ✅ 游戏结束弹窗显示最终得分
- ✅ 美观的渐变深色主题
- ✅ 响应式布局

## 操作说明

| 按键 | 功能 |
|------|------|
| ← / → | 左右移动 |
| ↑ | 旋转方块 |
| ↓ | 加速下落 |
| 空格 | 瞬间落底 |
| P | 暂停/继续 |

## 计分规则

- 1 行: 100 × 等级
- 2 行: 300 × 等级
- 3 行: 500 × 等级
- 4 行: 800 × 等级

每消除 10 行提升一个等级，下落速度会变快。

## 启动服务器

```bash
cd /root/.openclaw/workspace/tetris
python3 server.py
```

默认端口 8000，也可以指定端口：

```bash
python3 server.py 8080
```

然后在浏览器打开 `http://你的服务器IP:8000` 即可开始游戏。
